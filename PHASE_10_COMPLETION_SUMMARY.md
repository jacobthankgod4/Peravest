User navigates to /ajo/groups\n2. Browse tab shows all public groups\n3. Apply filters (frequency, amount, search)\n4. View group details on card\n5. Click \"Join\" to open modal\n\n### Join Request Flow\n1. User clicks \"Join\" on group card\n2. Modal checks eligibility (reliability score)\n3. If eligible:\n   - Show confirmation steps\n   - User submits request\n   - Request saved to DB\n   - User notified of submission\n4. If not eligible:\n   - Show reason\n   - Suggest improvements\n   - Option to try another group\n\n### Approval Flow\n1. Group owner views pending requests\n2. Reviews user info (name, email, date)\n3. Approves or rejects\n4. If approved:\n   - User added as member\n   - Position assigned\n   - User notified\n   - Request marked approved\n5. If rejected:\n   - Optional reason provided\n   - User notified\n   - Request marked rejected\n\n### My Requests Tab\n1. User views all submitted requests\n2. See status (pending/approved/rejected)\n3. Cancel pending requests\n4. View submission date\n5. Real-time status updates\n\n## Filters & Search\n\n### Available Filters\n- **Search**: Group name or invite code\n- **Frequency**: Daily, Weekly, Monthly\n- **Amount Range**: Min and max contribution\n- **Sort By**: Newest, Most Trusted, Most Active, Ending Soon\n\n### Filter Combinations\n- Find daily groups under ₦5,000\n- Find most trusted groups with 5+ members\n- Find groups ending soon\n- Search specific group by name\n\n## Eligibility Rules\n\n### Join Requirements\n- Reliability score ≥ group threshold (default 0.7)\n- Group not full (current_members < max_members)\n- Not already a member\n- No pending request for same group\n\n### Reliability Score Calculation\n- On-time contributions: +1.0\n- Late contributions: +0.8\n- Missed contributions: +0.0\n- Average across all groups\n- New users: 0.5 (default)\n\n## Real-time Features\n\n### Subscriptions\n- Group member count updates\n- New join requests (for owners)\n- Request status changes\n- Group status changes\n- Payout date updates\n\n### Notifications\n- Join request submitted\n- Request approved/rejected\n- New request received (owner)\n- Group full notification\n- Eligibility blocked notification\n\n## Database Tables Used\n\n```sql\n-- ajo_groups\nid, name, description, frequency, contribution_amount,\ncurrent_members, max_members, avg_reliability_score,\nstatus, is_public, created_at, next_payout_date,\nreliability_threshold, cycle_number, total_cycles\n\n-- ajo_join_requests\nid, user_id, group_id, status, created_at,\nreviewed_at, reviewed_by, rejection_reason\n\n-- ajo_memberships\nid, user_id, group_id, position, status, joined_at\n\n-- ajo_member_scores\nuser_id, score\n\n-- user_accounts\nId, FirstName, LastName, Email, phone_number\n```\n\n## API Endpoints (via Supabase RPC)\n\n```typescript\n// Browse\nGET /ajo/groups - List all public groups\nGET /ajo/groups/{id} - Get group details\nGET /ajo/groups/trending - Get trending groups\nGET /ajo/groups/search?q=name - Search groups\n\n// Join Requests\nPOST /ajo/join-requests -
